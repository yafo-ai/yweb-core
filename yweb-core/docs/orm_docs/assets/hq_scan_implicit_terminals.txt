========================================
判定
========================================

全部命中都是 `.all()` 显式终端。只是 `for` 开始后 `.all()` 出现在跨行表达式的末尾，
正则没跨行匹配所以看起来像「裸 query 迭代」。实际 Python 先执行 `.all()` 返回 list，
再由 `for` 迭代 list，**没有任何一处在迭代 Query 对象本身**。

对 HybridQuery 的含义:
- HybridQuery 的 `.all()` 在同步上下文直接返回 list，这些代码不受影响
- 以上 6 处都在 `def` 路由（已在 commit 0a5e5a8 把路由从 async def 改回 def），
  即使 HybridQuery 上线后，同步上下文行为不变
