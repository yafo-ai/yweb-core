========================================
对 HybridQuery 的含义
========================================

一旦 CoreModel.query 返回 HybridQuery，调用方传入 paginate 的「query」
可能是 HybridQuery 实例，而不是 sqlalchemy.orm.query.Query。此处
`isinstance(query_or_stmt, Query)` 将走到 else 分支 → 抛 TypeError。

Phase 3 / Phase 4 处置方案（任选其一）:
  A. 在 paginate() 入口先解包: 如果传入 HybridQuery，取 ._query 再走原分支
     改动最小，但 HybridQuery 内部属性被 paginate 依赖
  B. 显式识别: `if isinstance(query_or_stmt, (Query, HybridQuery)):`，
     在 HybridQuery 分支内部调用 ._query 后按 Query 流程处理
  C. 改 duck typing: `if hasattr(query_or_stmt, 'count') and hasattr(query_or_stmt, 'offset'):`
     HybridQuery 透传所有链式方法，天然兼容；但容错更宽松、误伤风险高

推荐 B（显式）。Phase 3.2 在实现 HybridQuery.paginate 时一并处理。
